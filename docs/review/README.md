## ファイルの役割

| ファイル | 役割 | 誰が書くか |
|---|---|---|
| `2026-*.md` | 最新レビュー1本 | **レビュアー（Codex）。こちらは書き換えない** |
| [review_template.md](review_template.md) | レビューに書く内容の様式 | こちらが持ち、レビュアーへ渡す |
| [findings.md](findings.md) | **指摘の受付簿** — 全件と、その処遇 | こちらが書く |

**受付簿が要る理由。** 「総評で問題と書いたものは課題台帳へ起票する」という規則は
[CLAUDE.md](../../CLAUDE.md) と [document_map](../dev/document_map.md) の2箇所に以前からあり、
**それでも 2026-08-01 の総評の指摘4件が2日間どこにも追跡されなかった**。
規則を増やしても直らないので、**全指摘の処遇を1枚で見えるようにし、機械検査で取りこぼしを検出する**形にした。

> **受付簿の内容は薄く保つ。** 受付簿は「存在と処遇」、進行中の対応内容は
> [_wip/current_issues.md](../_wip/current_issues.md) が持つ。過去レビューの原文が必要なら
> git履歴から読む。両方へ詳細を書くと必ず片方が古くなる。
