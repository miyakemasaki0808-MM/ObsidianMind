## 適用条件

Explore のモード・照合の規則・範囲のチップ、Vault 全体の走査の除外と共有（`NoteScanCache`）を変えたときに使う。

### 走査の本数と一覧の寿命は「走査の記録」の行で判定する

**「読んでいます」の表示だけでは判定しない。** 一度一覧を受け取った後は、開き直しても前の一覧で照らすので表示が出ず、裏で走査し直していても見分けられない。
**本文が出た時刻も起点にしない。** 寿命は走査を終えてから数えるので、本文の読み込みに12秒かかれば「本文から50秒」は走査の完了から62秒にあたる。既に持っている一覧で引いたときは、本文が新しくても寿命は延びない。

Debug APK は、走査を始めたときに `VigilithNoteScan: started`、一覧を公開したとき（寿命の起点）に `VigilithNoteScan: published` を logcat へ1行ずつ出す（Vault もノートも載らない）。

```text
adb -s <serial> shell date '+%m-%d %H:%M:%S.000'
adb -s <serial> logcat -d -T '<採った時刻>' -s VigilithNoteScan:I
```

| 判定 | 条件 |
|---|---|
| **寿命の中** | 直前の `published` から60秒未満で一覧を要求し、その後の `started` が**0行** |
| **切れた後** | 直前の `published` から60秒以上で一覧を要求し、その後の `started` が**1行**（ちょうど60,000msは切れた側） |
| **観測不成立** | 起動後の最初の要求で `started` と `published` が1行ずつにならない、時刻を採り損ねた、logcat を読めなかった |

**観測不成立は未判定として記録し、合格に数えない。** 起点は常に、要求の時点で直前にある `published` である。本文の保存など一覧を捨てる操作は挟まない。
端末では境界を狙わず3秒以上空ける。60,000msの境界は `NoteScanCacheTest` が持つ。

## 検証前

- **一時Vaultに次のノートを置く。** 生成した原本とマニフェストは証跡へ残す
  - **階層の違うノート:** `習慣.md`（直下）・`習慣化のメモ.md`（直下）・`ideas/読書の習慣.md`・`ideas/2026/深い階層の習慣.md`
  - **名前が前方で重なるフォルダ:** `ideas2/別フォルダの習慣.md`
  - **同じ名前のノート:** `メモ.md`（直下）・`ideas/メモ.md`・`books/メモ.md`
  - **大文字小文字と空白:** `Deep Work ノート.md`
  - **外すフォルダ:** `.obsidian/除外の確認.md`・`_AI補記/除外の確認.md`・`_ReadingTraces/除外の確認.md`
  - **`.obsidian` の痕跡:** `.obsidian/除外の確認.md` を相対パスに持つ痕跡を `_ReadingTraces/` に1件置く（旧版で読んだノートの痕跡にあたる）。別のフォルダに、ノートを消した普通の痕跡も1件置く
  - **タイトルに無い言葉の材料:** 本文にだけ「継続のコツ」と書いたノート（タイトルには含めない）
- **走査の待ちを見るケースだけ、3,000本ほどの大きな Vault を使う。** 走査の時間を測ったときの合成 Vault の生成手順は `_wip/` にある
- 開いた Fold と閉じた画面（スマホの形）の両方で行う。AI の選定そのものを見るケースは Nano が使える端末で行い、使えなければ未実施とする

## 射程外（自動テストが持つ順序）

- 走査の途中で最初に頼んだ人が取り消される順序、走査の失敗、走査の途中の本文の書き換え（`NoteScanCacheTest`）
- 一覧を待つ間の範囲の切替、照らしの途中の打ち直し、一覧が返る直前の Vault 切替（`SearchControllerTest`）

## 後処理

- 共通手順の後処理に従う。一時Vaultと3,000本の Vault を消す。
- **元Vaultへは戻さず、常設の検証用Vaultで終える。**

## 記録

- 通したケースIDと結果、`EXPLORE-11`〜`EXPLORE-13`・`EXPLORE-20`・`EXPLORE-21` の走査の記録の行と時刻、「読んでいます」が出たか、結果が出るまでのおおよその秒数。
- オーナーの体感（タイトルから探す頻度、AI のモードへ移る場面）は合否と分けて残す。
- 測っていないもの: 「すべて」でタイトルが近い40本に絞ったときの再現率。
