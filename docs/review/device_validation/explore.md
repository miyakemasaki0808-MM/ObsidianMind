# Explore の実機検証ケース

## 正本

- タイトルのモード・AI のモード・範囲・走査の共有: [ai_picker](../../dev/features/ai_picker.md)（§3〜§5・判断7〜判断10）
- 対象から外すフォルダと走査の共有: [rediscover](../../dev/features/rediscover.md) §5
- 共通の準備・観測・後処理: [README](README.md)。新しい画面の形なので**通し版**で行う

## 適用条件

Explore のモード・照合の規則・範囲のチップ、Vault 全体の走査の除外と共有（`NoteScanCache`）を変えたときに使う。

## 検証前

- **一時Vaultに次のノートを置く。** 生成した原本とマニフェストは証跡へ残す
  - **階層の違うノート:** `習慣.md`（直下）・`習慣化のメモ.md`（直下）・`ideas/読書の習慣.md`・`ideas/2026/深い階層の習慣.md`
  - **名前が前方で重なるフォルダ:** `ideas2/別フォルダの習慣.md`
  - **同じ名前のノート:** `メモ.md`（直下）・`ideas/メモ.md`・`books/メモ.md`
  - **大文字小文字と空白:** `Deep Work ノート.md`
  - **外すフォルダ:** `.obsidian/除外の確認.md`・`_AI補記/除外の確認.md`・`_ReadingTraces/除外の確認.md`
  - **`.obsidian` の痕跡:** `.obsidian/除外の確認.md` を相対パスに持つ痕跡を `_ReadingTraces/` に1件置く（旧版で読んだノートの痕跡にあたる）。別のフォルダに、ノートを消した普通の痕跡も1件置く
  - **タイトルに無い言葉の材料:** 本文にだけ「継続のコツ」と書いたノート（タイトルには含めない）
- **走査の待ちを見るケースだけ、3,000本ほどの大きな Vault を使う。** 走査の時間を測ったときの合成 Vault の生成手順は `_wip/` にある
- 開いた Fold と閉じた画面（スマホの形）の両方で行う。AI の選定そのものを見るケースは Nano が使える端末で行い、使えなければ未実施とする

## ケース

**狙いのケースを先に置く**（→ [L59](../../dev/lessons/L59.md)）。

| ID | 入力・操作 | 期待 |
|---|---|---|
| `EXPLORE-01` | **狙い：タイトルが分かっているノートへ、フォルダを選ばずに着く。** アプリを起動し Explore を開いて「深い階層」と打ち、出た行を押す | フォルダを1度も選ばずに `ideas/2026/深い階層の習慣.md` が出て、押すと本文の先頭から開く |
| `EXPLORE-02` | Explore を開く。別のタブへ移って戻る。打ってから戻る | いつもタイトルのモードで入力欄は空。範囲のチップもランダムのボタンも無い。打つ前は今日読んだノートが出る |
| `EXPLORE-03` | 「習慣」と打つ | `習慣.md` → `習慣化のメモ.md` → 部分一致の順に、3件に限らず全部出る |
| `EXPLORE-04` | 「deepwork」「DEEP WORK ノート」と打つ。「md」と打つ | 前の2つで `Deep Work ノート.md` が出る。「md」では全ノートが出ない |
| `EXPLORE-05` | 「メモ」と打つ | 同じ名前の3行に `books`・`ideas`・`ルート直下` が添えられ、`習慣化のメモ.md` には添えられない。押すとそれぞれ別のノートが開く |
| `EXPLORE-06` | 「除外の確認」と打つ。AI のモードのチップを見る。Rediscover を10回引く | タイトルの結果に出ない。チップに `.obsidian`・`_AI補記`・`_ReadingTraces` が無い。Rediscover にも出ない |
| `EXPLORE-07` | 日本語入力で「しゅうかん」と打って変換し確定する。途中で変換をやり直す | 入力が崩れない。確定すると `習慣` の結果になる |
| `EXPLORE-08` | 確定キーを押す（タイトルのモード・AI のモード） | キーボードが閉じるだけで、AI の検索が始まらない |
| `EXPLORE-09` | 「継続のコツ」と打つ（タイトルに無い）。出た1行を押す | タイトルに見つからない旨と AI へ移る1行が出る。押すと AI のモードへ移って同じ言葉で検索が始まり、範囲は「すべて」 |
| `EXPLORE-10` | AI のモードへ移る。範囲を見る。「ideas」を選んで「習慣」で探す。「すべて」へ戻す | 最初は「すべて」が選ばれ注記が出る。「ideas」では注記が消え、`ideas` の奥まで選ばれて `ideas2` は選ばれない。戻すと結果が消えて注記が出る |
| `EXPLORE-11` | 3,000本の Vault で Rediscover を1回引き、本文が出てから50秒以内に Explore を開いて打つ（寿命は走査を終えてから60秒。本文が出るのはその少し後なので、余裕を取る） | 「読んでいます」が出ず、すぐ結果が出る |
| `EXPLORE-12` | 3,000本の Vault で Explore を開いたまま70秒置いてから打つ | 打っている途中に「読んでいます」が出ない |
| `EXPLORE-13` | 3,000本の Vault で起動直後に Explore を開き、走査の途中で打つ。別の回に、Rediscover の走査の途中で Explore を開いて打つ | 「読んでいます」が出て、走査が終わると押さずに結果へ替わる。途中で画面が固まらない |
| `EXPLORE-14` | 3,000本の Vault で1文字打ち、続けて打ち、結果を末尾まで送る | 入力が遅れず、スクロールが止まらない |
| `EXPLORE-15` | 検索の後に Vault を切り替えて Explore を開く | 旧 Vault の結果・チップ・選んだ範囲が残らない。新しい Vault のノートだけが出る |
| `EXPLORE-16` | カバー画面を横にして開き、打つ。AI のモードへ移す | 送れば結果とボタンに届く。見出しの霞が画面の端まで届く |
| `EXPLORE-17` | ダークとライトで、モードのチップ・注記・結果の行を見る | 文字が読める。行どうしが1枚のパネルに見える |
| `EXPLORE-18` | TalkBack でモードのチップに触れる | 選択中か未選択かが読み上げられる |
| `EXPLORE-19` | オプション →「データ管理」→「読書痕跡を整理」を開く | `.obsidian` の痕跡は候補に出ない。ノートを消した普通の痕跡は候補に出る |

## 射程外（自動テストが持つ順序）

- 走査の途中で最初に頼んだ人が取り消される順序、走査の失敗、走査の途中の本文の書き換え（`NoteScanCacheTest`）
- 一覧を待つ間の範囲の切替、照らしの途中の打ち直し、一覧が返る直前の Vault 切替（`SearchControllerTest`）

## 後処理

- 共通手順の後処理に従う。一時Vaultと3,000本の Vault を消す。
- **元Vaultへは戻さず、常設の検証用Vaultで終える。**

## 記録

- 通したケースIDと結果、`EXPLORE-11`〜`EXPLORE-13` で「読んでいます」が出たかと、結果が出るまでのおおよその秒数。
- オーナーの体感（タイトルから探す頻度、AI のモードへ移る場面）は合否と分けて残す。
- 測っていないもの: 「すべて」でタイトルが近い40本に絞ったときの再現率。
