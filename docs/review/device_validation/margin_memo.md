# 余白メモの実機検証ケース

## 正本

- 痕跡そのもの（欄・保存・寿命）: [reflect_reading_trace](../../dev/features/reflect_reading_trace.md)
- 退避と読み戻し: [reading_trace_backup](../../dev/features/reading_trace_backup.md)
- 共通の準備と後処理: [実機検証手順](README.md)

## 適用条件

余白メモの入力・保存・削除・合流、痕跡スキーマ v7 への移行を触ったときに使う。
**旧版の痕跡を持つVaultで一度は必ず通す** — ひとことの3欄を読み捨てる経路があり、
そこを誤ると**訪問履歴まで一緒に消える**。

## 検証前

- 一時Vaultに、**v7 より前に作った痕跡を持つノート**を最低1つ残す。
  **v6 だけでなく、手元に v3 の痕跡があればそれも入れる** — 旧欄が入った版が違うので、
  v6 だけでは版窓の誤りを踏めない。
- 痕跡ファイルの中身を前後で比べられるよう、`_ReadingTraces/*.json` を検証前に控える。
- 上限（20件）に当てるケースがあるので、1ノートへ19件まで入れた状態を作っておく。
- **端末AIは関係しない。** Nano が使えない状態でも全ケースが通ること自体が確認項目。

## ケース

| ID | 入力・操作 | 期待 |
|---|---|---|
| `MEMO-01` | ノートを開き、ヘッダの `✎` を押す | シートが上がる。**本文のスクロール位置が動かない** |
| `MEMO-02` | 何か書いて「置く」 | 一覧の先頭に増え、入力欄が空になる。**シートは閉じない**（続けて書ける） |
| `MEMO-03` | **初読のノート**（まだ一度も離れていない）で置き、10秒未満で別のノートへ移る | 「このノートを離れるときに保存します」と出たあと、戻ると**メモが残っている**。門番の例外が効いている |
| `MEMO-04` | 19件ある状態で2件足す | 20件目は置ける。21件目で「いっぱいです」と出て、**入力欄の文字が消えない** |
| `MEMO-05` | 1件消す → 確認で「消す」 | 一覧から消える。アプリを再起動しても**復活しない** |
| `MEMO-06` | 目安（200字）を超える長さを書く | 「少し長めです」と出るだけで、**そのまま置ける** |
| `MEMO-07` | 上限（1,024バイト）を超える長さを置く | 置けたうえで「ここまでを置きました」と出る。**黙って切らない** |
| `MEMO-08` | 旧版の痕跡を持つノートを開き、10秒以上読んで離れる | `_ReadingTraces` の当該ファイルが **v7 になり、`remark`／`reply`／`mirrored` が消え、`visits` は件数ごと残る** |
| `MEMO-09` | `MEMO-08` のノートを Rediscover で引き当てる | 再会カードが従来どおり出る（**痕跡が破損扱いになっていない**） |
| `MEMO-10` | メモがあるノートを Rediscover で引き当てる | カードに `前回のメモを見る` が出て、押すとシートが開く |
| `MEMO-11` | 端末側20件・退避ファイル側に別の1件がある状態で読み戻す | 下見に**保留の件数**が出て、「どちらのメモも消えません」と書かれる。確定しても端末側が変わらない |
| `MEMO-12` | 端末側と退避側に別々のメモがある（合計が上限内）状態で読み戻す | **両方のメモが残る**。日時の順に並ぶ |
| `MEMO-13` | 全画面表示（`⛶`）にする | `✎` は出ない。`✕` で戻ると押せる |
| `MEMO-14` | AIタブを開く | **ひとことの入口が無い**。タブのバッジも出ない |

## 後処理

- 共通手順の後処理に従う。一時Vaultと控えた JSON を消す。
- **元Vaultへは戻さず、常設の検証用Vaultで終える**（戻す操作自体が読書痕跡を増やすため）。
- 検証で作った痕跡ファイルは一時Vaultごと消えるので、個別の削除は要らない。

## 記録

- 通したケースIDと結果、`MEMO-08` で確認した **v7 移行後のJSONの差分**（消えた欄・残った訪問数）。
- `MEMO-11` で出た保留件数と、確定後に端末側が無変更だったこと。
- 測っていないもの: シートの体感、IME の挙動、20件という上限がユーザーにとって足りるか。
