# 蒸留の実機検証ケース

## 正本

- 機能契約・定数・書き込み・復旧: [reflect_distill](../../dev/features/reflect_distill.md)
- 共通の準備と後処理: [Codex実機検証手順](README.md)

数値は実行時に正本と `DistillLimits` を読み直す。本書のケース名だけを見て、以前の値を固定値として使わない。

## 適用条件

候補モデル、文・句分割、候補選定、AI応答ID、候補カード、太字率、書き込み、復旧、
保存後の状態リセットを変更したときに使う。

- 候補生成だけの変更: `DIST-01`〜`DIST-08`
- カード表示・選択の変更: 上記＋`DIST-09`
- 書き込み・復旧の変更: 全ケース。少なくとも `DIST-10`〜`DIST-13` を省略しない
- 不具合修正: 該当ケースに加え、隣接する境界の前後1件を実行する

## 検証前

- 一時Vault以外では保存しない。
- fixtureは1ケース1ノートを基本とし、AIが候補を選ばない場合でも候補集合をUIから判定できる量に絞る。
- 文字数境界はKotlin `String` と同じ原文オフセット基準で事前計測し、レビューへ実測文字数を書く。
- 保存ケースでは、push前の原文をローカルに残す。

## ケース

| ID | 入力・操作 | 期待 |
|---|---|---|
| `DIST-01` | 分割閾値以下の通常文を1文だけ置き、蒸留する | 文全体が1候補。親文と候補範囲は同じ |
| `DIST-02` | 分割閾値を超える1文を、最小句長以上の2断片＋`、`で作る | 2句が候補になり、親文全体は候補にならない。カードは親文を文脈表示する。件数・短いノート例外・保存プレビューは句を文全体と誤認させない |
| `DIST-03` | `DIST-02` の境界をASCII `,` にする | 日本語読点と同じ句範囲になる |
| `DIST-04` | 分割閾値超だが読点のない1文 | 無理に割らず、文全体が1候補 |
| `DIST-05` | 通常句／wikilink列だけの句／通常句を1文にする | リンク句だけが候補から消え、前後の通常句は残る |
| `DIST-06` | インラインコード内の読点と、コード外の読点を同じ長文へ置く | コード内では割らず、コード外だけを境界にする。記法途中へ太字境界を置かない |
| `DIST-07` | 分割閾値の直前・ちょうど・直後を3ノートで作る | 正本の「超えると分割」が境界どおり。短い側を細切れにしない |
| `DIST-08` | 親文上限のちょうど・1超過を、`、`・`,`・読点なしで作る | 上限超過の**親文**は分割後の句長にかかわらず候補0件。上限内は通常どおり |
| `DIST-09` | 3句の中央をリンク句にしてカードを見る | 表示位置の契約どおりで、除外された句を候補本文として表示しない |
| `DIST-10` | 長文から1句だけ選択し、プレビュー後に一時ノートへ保存する | 選択句だけが `**` で囲まれ、親文全体は囲まれない |
| `DIST-11` | 保存後ファイルをpullし、今回追加した `**` だけを除いて原文と比較する | 原文と完全一致。BOM・CRLF・絵文字より後ろの位置も不変 |
| `DIST-12` | 保存プレビュー後、外部から一時ノートを変更して保存する | 競合として中断し、外部編集と元本文を壊さない |
| `DIST-13` | 保存の各段階で失敗させ、再起動後に復旧UIを開く | 正本の復旧分岐どおりに復元・維持・再確認でき、復旧レコードが不正に残らない |
| `DIST-14` | 同じ文を複数箇所へ置き、一方のIDだけを選ぶ | 選んだ原文位置だけが変わる |
| `DIST-15` | frontmatter、見出し、コードフェンス、テーブル、既存太字を含む | 対象外領域は不変で、重なる候補は出ない |
| `DIST-16` | 保存前に要約・関連・ひとこと・セクションチャット・クイズの状態を作る | 保存後も正本の維持／破棄契約どおり |
| `DIST-17` | 読点で2句に分割される文Aの直後へ未分割の短文Bを置き、Bのカードを見る。対照として未分割文Aの直後へ同じBを置く | Bの文脈は直前候補単位の親文A全体。分割文Aでは末尾句だけに縮まず、未分割文Aでも従来どおり全文を表示する |
| `DIST-18` | 1文内に同じ括弧内語句を2回、別の括弧内語句を2種類置いて蒸留する | 同じ表層語句は1カードだけ、語句カードは最大2件。各語句と重なる親文カードは同時に出ず、文脈は親文全体。位置は親の線形位置を借り、カードは語句種別、件数は「箇所」と分かる |
| `DIST-19` | 括弧内語句だけが残る最小fixtureをプレビューし、一時ノートへ保存してpullする | 確認・完了は「箇所」で数え、例外なく保存できる。括弧の内側だけが `**` で囲まれ、括弧・親文・その他の原文は不変で、追加した `**` を除けば保存前と完全一致 |
| `DIST-20` | 斜体 `*…*`・打ち消し線 `~~…~~` を含む長文（読点つき）と、装飾の内側に句点がある文を置いて蒸留し、保存してpullする | 装飾の対を片側だけ含む候補が出ない。保存後、装飾の対象文字列が変わらず、Obsidianでの描画も保存前と同じ。掛け算の `*`・コード内の `*`・エスケープした `\*` を含む文は従来どおり候補になる。**リスト項目・引用行に未閉じの `*` が並んでも候補が消えない。リンク（`[a*b](url)`・`[[a*b]]`）の記号が外側の装飾と対にならない。`\*` はバックスラッシュを出さず記号だけが描かれる** |

AIが返した候補の重要性そのものは合否にしない。候補IDがアプリの候補集合内であり、
表示・選択・保存がそのIDの原文範囲へ解決されることを判定する。

## 後処理

- 元Vaultへ戻し、一時Vault、退避フォルダ、UIダンプを削除する。
- 保存したfixtureは原状回復せず、一時Vaultごと削除する。元Vaultへコピーしない。
- 復旧ケースでは、アプリ内の復旧情報が一時Vaultを指したまま残っていないことを確認してから削除する。
