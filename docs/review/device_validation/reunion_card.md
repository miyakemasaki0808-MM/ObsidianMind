# 再会カードの実機検証ケース

## 正本

- 枠の規則・優先順位・種別: [reunion_card](../../dev/features/reunion_card.md)
- 痕跡そのもの（欄・保存・寿命）: [reflect_reading_trace](../../dev/features/reflect_reading_trace.md)
- 共通の準備と後処理: [Codex実機検証手順](README.md)

## 適用条件

再会カードの枠に出すもの・種別・「まだ考えたい」の印・候補の列挙規則を変えたときに使う。
**痕跡スキーマを上げたときも必ず通す**（v6 で欄が4つ増えている）。

## 検証前

- **カードは Rediscover 経路でだけ出る。** さがす・関連から開いても出ないので、
  ひくボタンで対象ノートを引き当てるまで繰り返すか、一時Vaultのノート数を絞る。
- **2回目の訪問以降でないと枠が出ない**（1回では「俯瞰」にならない）。
  対象ノートは事前に2回以上開いて痕跡を作る。
- fixture は3種類そろえる。**問いを含むノート**（「〜だろうか。」で終わる文がある）、
  **版番号や現状の記述を含むノート**、**どちらも無いノート**。
- 旧版の痕跡が読めることを見るため、**v6 より前に作った痕跡を持つノート**も1つ残しておく。

## ケース

| ID | 入力・操作 | 期待 |
|---|---|---|
| `REUNION-01` | 問いを含むノートを2回以上開き、Rediscover で引き当てる | 「前回のあなたはこの問いで止まっていました」の前置きと、**本文にある文がそのまま**出る |
| `REUNION-02` | 版番号や「現在は〜」を含むノート（問いは無い）で同じ操作 | 「今も有効か確認したい箇所があります」の前置きと該当の記述が出る |
| `REUNION-03` | 問いも古い前提も無いノートで同じ操作 | 従来どおり俯瞰要約が出る。**前置きは付かない** |
| `REUNION-04` | 枠が出ている状態で「まだ考えたい」を押す | 表示が即座に切り替わる。サイドカーに `markedSummary` / `markedKind` / `markedAt` が入る |
| `REUNION-05` | 印を付けたノートを次に引き当てる | 「前回『まだ考えたい』と印を付けています」＋**押したときと同じ文**。**AI生成が走らない**（待ち時間ゼロ） |
| `REUNION-06` | 印のあるカードで「読んだ」を押し、再度引き当てる | **印は外れていない**（閉じる操作と取り消しは別） |
| `REUNION-07` | 印をもう一度押す | 印が外れ、サイドカーから3欄が消える |
| `REUNION-08` | 枠が空（空振り・AI不可）のカードを見る | 「まだ考えたい」が**出ない**。見出しの1文だけで意味が通る |
| `REUNION-09` | 同じノートを続けて2回引き当てる（訪問数が変わらない範囲で） | 2回目は生成が走らない。**空振りだった回も生成し直さない** |
| `REUNION-10` | v6 より前に作った痕跡を持つノートを引き当てる | 破損扱いにならず、俯瞰要約として表示される |
| `REUNION-11` | 生成中にノートを切り替える | 旧ノートの枠が新しいカードへ出ない。走行表示が残らない |
| `REUNION-12` | `ReadingTraceCardPanelTest` を `am instrument` で実行する | 6件すべて成功。種別ごとの前置きと印の文言が描画で確認される |

## 後処理

- 一時Vaultを削除し、元Vaultへ戻す。
- 検証で付けた印は一時Vault内なので、Vaultごと削除すれば残らない。
