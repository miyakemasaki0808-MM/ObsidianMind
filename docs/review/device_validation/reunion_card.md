# 再会カードの実機検証ケース

## 正本

- 枠の規則・優先順位・続きから読む: [reunion_card](../../dev/features/reunion_card.md) 判断6・7
- 低い横画面の2列化: [rediscover](../../dev/features/rediscover.md) 判断6
- 痕跡の欄・保存・寿命: [reflect_reading_trace](../../dev/features/reflect_reading_trace.md)
- 準備と後処理: [実機検証手順](README.md)

## 適用条件

再会カードの内容、生成と保存の条件、ボタン、再開先、痕跡スキーマ、低い横画面の配置を変えたときに使う。UI・新しい保証・スキーマに触れたときは通し版とする。

## 検証前

- カードは Rediscover 経路でノートを引いたときに出る。1回目の訪問から対象になる。対象を確実に引く場合は1ノートだけの一時Vaultを使う。
- 途中の痕跡と読了の痕跡、本文中の問い・古い前提・どちらも無いノート、旧 `Overview`・`Question` の痕跡、撤去前の印を持つ痕跡を用意する。
- 旧 `REUNION-04`〜`08`・`13` の印操作は撤去済みで実行しない。保存済みの印は画面へ出さず、痕跡の3欄は保持する。
- Nanoの呼出回数や保存保留など、画面だけで判定できない項目は、実機計測・保存ファイル・制御したJVM検査の観測を区別して記録する。

## ケース

| ID | 入力・操作 | 期待 |
|---|---|---|
| `J6-01` | 途中45%・見出しのあるノートを引き、「続きから読む」を押す | 読み進めた節・到達率と前後の要約2文が出る。ボタンでカードは即時に畳まれ、その位置の少し手前へ送られる |
| `J6-02` | 前後の要約を作る→同位置を10秒以上読む→離れて再会。その後、先へ読み進めて再会 | 同じ位置・同じ本文なら端末内の保存文を再掲し生成を増やさない。先へ進んだときだけ前後の要約を更新する。実機で生成回数を直接数えられない場合は部分確認とする |
| `REUNION-01` | （別名 J6-03a）読了100%で本文に問いを持つノートを引く | 「前回のあなたはこの問いで止まっていました」と本文そのままの問いが出て、続きボタンは出ない |
| `REUNION-02` | 読了100%で古い前提の記述があるノートを引く | 前置き「今も有効か確認したい箇所があります」と原文が出て、続きボタンは出ない |
| `REUNION-03` | （別名 J6-03b）読了100%で問い・古い前提の候補が無いノートを引く | ノートの要約の先頭1文が前置きなしで出る。旧俯瞰要約を新たに作らず、続きボタンも出ない |
| `J6-04` | （別名 REUNION-10）途中の旧 `Overview`・`Question`、読了の文を持つ旧 `Overview` をそれぞれ引く | 旧形式を破損扱いにしない。途中は保存済みの旧文を使わず前後の要約、読了は選別し直して問い・古い前提・ノートの要約のいずれかを出す |
| `J6-05` | 訪問1回・途中30%のノートを引く | 1回目の再会でも前後の要約と続きボタンが出る |
| `J6-07` | 途中90%で手前に画像を持つノートを再開し、画像の後ろを読む。末尾が画面外に残る長文対照も使う | 画像を飛び越した位置へ送られ、読んだ後ろの進捗を実保存する。送っただけで末尾100%にはしない。遅延loader中に実NavHostをまたぐ順序は別に注入が必要 |
| `J6-08` | 前半・中盤・終盤に固有の文がある長い1ブロックの10%地点を引く | 既読側に未読末尾だけを入れず、前後の要約2文を出す。生成した境界記号は表示・保存しない。モデル文面から位置を判別できなければ部分確認とする |
| `J6-09` | 途中まで読んで前半へ戻る順序、末尾まで読んで前半へ戻る順序をそれぞれ作り、離れて再会 | 前者は最高到達率・その前後の要約・続きボタンを維持し、後者は100%・読了扱い・続きボタンなし。最後に見た位置へ巻き戻さない |
| `REUNION-09` | 訪問を増やさず同じノートを引き直す | 前後の本文と位置が同じなら保存済みの要約を再利用する。空振りの再試行条件は正本の判断6に従う |
| `REUNION-11` | 要約を生成中に別ノートへ切り替える | 旧ノートの結果と走行表示を新ノートへ持ち越さない |
| `J6-11` | 高さ480dp未満の横画面で途中痕跡・メモ付きカードを出す | 左にカード、右にノート名と本文を表示する。「読んだ」へスクロールで到達して押せ、マスコットがカードの操作を塞がない |
| `J6-12` | 痕跡の無いノートを10秒以上読み、直ちに同じノートを引き直す | 最初の再会で1訪問目のカードが出る。もう1回の引き直しを要しない |
| `J7-01` | 撤去前の印を持つ途中・読了痕跡を引き、離れて実保存する | 印の文と「まだ考えたい」は表示しない。途中は前後の要約、読了は現行の選別。保存後も `markedAt`・`markedSummary`・`markedKind` を残す |
| `J6-10` | （別名 REUNION-12）本体を停止し、対象端末を指定して `ReadingTraceCardPanelTest`、`NoteReadingFlowTest`、実Nanoの前後要約テストを `am instrument` で実行する | カード9件・読書14件・Nano1件がすべて成功する。低い横画面でノート名・本文・「読んだ」への到達も検査する |

## 後処理

常設検証用Vaultへ切り替えて固定の待機ノートを確認してから、共通手順の分担に従い一時Vaultを片付ける。元Vaultへは戻さない。
