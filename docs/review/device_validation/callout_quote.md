# 引用とコールアウトの中の実機検証ケース

## 正本

- 引用の中の読み方・コールアウトの頭・見開きでの割り方: [markdown_rendering](../../dev/system/markdown_rendering.md) §8
- 引用して書く・照らし直し: [margin_quote](../../dev/features/margin_quote.md)（§5.5・§11）、既存ケース [margin_quote](margin_quote.md)
- 見開き: [note_spread](../../dev/features/note_spread.md) §5
- 共通の準備・観測・後処理: [README](README.md)。見た目を変えたときは**通し版**で行う

## 適用条件

引用・コールアウトの解析（中のブロック・頭の種類と題）、引用とコールアウトの描画（本文・見開き・並べ読みの右の面）、
コールアウトの頭の並べ方（言葉と題を同じ行にするか次の行へ送るか）、引用の中の照らし直しの文字を変えたときに使う。

## 検証前

- **一時Vaultに次のノートを置く。** 原本とマニフェストは証跡へ残す。
  - **コールアウトと引用:** 素の引用（2行の段落・表・箇条と入れ子の箇条・チェック済みの項目・`>>` の入れ子）、
    5つの役割のコールアウト（`[!quote]`・`>[!NOTE]`（大文字・`>` の後に空白なし、中に表）・`[!question]`・`[!warning]-`・`[!tips]+`）、
    知らない種類 `[!MyRole]`、とても長い知らない種類名（「独自」×40）と末尾に目印のある長い題、
    「引用して書く」の節（`[!note]` の中に、末尾に空白のあるコードの行と、その後の段落）。冒頭で次のノートへ wikilink する
  - **並べ読みの資料:** `[!important]` のコールアウト（中に箇条・表・入れ子）と、見開きを数ページにまたぐ長い引用
    （とても長い知らない種類名の長い題、見出し・箇条3種・入れ子・表の行・コードを番号つきの目印で繰り返す）
- **開いた Fold（見開き・並べ読み）と、閉じた画面（カバー画面）の両方で、ライトとダークで行う。**

## ケース

| ID | 入力・操作 | 期待 |
|---|---|---|
| `CALLOUT-01` | カバー画面で「本文の引用」「役割と題」を明暗両方で開く | 引用の中の表は表、箇条は字下げした箇条、`>>` は入れ子の引用として出る。5つの役割の記号・言葉・題が出て、印の文字（`[!note]` など）は出ない。大文字・空白なし・`+`・`-` も開いた本文で出る。知らない種類は書かれたままの名前で出る。長い種類名では題が次の行へ送られ、題の末尾まで読める。記号は単色の文字で、注意は三角形（外観は代表の画像で判定） |
| `CALLOUT-02` | 開いた Fold の見開きで「コールアウトと引用」を明暗両方、「並べ読みの資料」の長い引用を最後のページまで送る | どちらも2面に組まれ、役割・表・長い題の末尾まで出る。長い引用は、子の先頭・リストの項目の先頭と途中でページが変わっても、目印が欠けずに順に1回ずつ出る。表の行はページの途中で割れない。境目の近くに大きな空白が無い |
| `CALLOUT-03` | 「コールアウトと引用」の関連から「並べ読みの資料」を右の面に開く | 左のノートを保ったまま右に開き、`important` は「まとめ」の言葉で、題・箇条・表・入れ子が描かれる |
| `CALLOUT-04` | 「引用して書く」の節で、題と次の文を選び、またコードから次の段落までを選んで引用し、メモを置いてから引用を押す | 選択に記号と種類の言葉が入らない（題から次の文まで選ぶと題と文だけ）。コードの末尾の空白は入らない（`foobar`）。引用を押すと元の節へ戻る。痕跡の引用の文字と前後の文字が保存され、元のノートは変わらない |
| `CALLOUT-05` | `com.example.newproject.ui.CalloutHeaderUiTest` と `com.example.newproject.ui.QuoteSelectionUiTest` を直接実行する | すべて完走する（境い目の3つの幅のテストを含む）。失敗・skip を成功に数えない |
| `CALLOUT-06` | TalkBack を有効にして、コールアウトの頭を読ませる | 種類の言葉と題が読まれ、記号の名前は読まれない。アクセシビリティの階層では言葉が `content-desc`、題が別の文字のノードで、記号は出ない |

## 後処理

- 常設検証用Vaultへ切り替え、ケース別一時Vault・UIダンプを削除する。`CALLOUT-04` で一時Vaultに書いた読書痕跡も一時Vaultと一緒に消える。元Vaultへは戻さない。
- TalkBack を有効にしたら、元の状態へ戻す。

## 記録

- 画面（カバー画面・開いた Fold）とテーマごとの合否。外観の画像は代表だけ
- 見開きで、ページの境目になった目印（子の先頭・項目の先頭と途中）と、欠け・重複・空白の有無
- 引用して書くで取れた文字と、痕跡に保存された引用の文字・前後の文字
- instrumentation の件数（失敗・skip を含む）
- TalkBack で実音声を確かめた役割と、読み上げ用のノードだけで確かめた役割

色・紙に敷く面・独自のアイコンは扱っていない（決まっていない）。AI へ渡す文と索引が変わらないことは JVM の `QuoteConsumersUnchangedTest` が持つ。
見開きで、子の間やリストの項目の間の余白の差だけで次の行の収否が変わる寸法は、このケースでは個別に作らない（数え方は JVM テストが持つ）。
