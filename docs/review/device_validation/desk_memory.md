# 机の記憶の実機検証ケース

## 正本

- 何を「並べた」とみなし、どう残し、再会でどう返すか: [desk_memory](../../dev/features/desk_memory.md)（§5・§6・§10・判断2〜4・判断9・判断10）
- 再会カードの枠とボタンの列: [reunion_card](../../dev/features/reunion_card.md)。並べ読みと右の面: [margin_pane](../../dev/features/margin_pane.md) §5.9・[margin_quote](../../dev/features/margin_quote.md) §5.6
- 痕跡の欄とスキーマ: [reflect_reading_trace](../../dev/features/reflect_reading_trace.md) §5・§6。退避と読み戻し: 既存ケース [reading_trace_backup](reading_trace_backup.md)
- 共通の準備・観測・後処理: [README](README.md)。新しい保証・UI・痕跡スキーマ v9 なので**通し版**で行う。スキーマを上げたので [reading_trace_backup](reading_trace_backup.md) も全件通す

## 適用条件

並べ読みの右に資料として見えていた時間の数え方、訪問に残す並べた相手、再会カードの名前の行と名前から並べて開く入口、
痕跡の訪問の欄・上限・切り詰め、走査の結果から相対パスを引く口を変えたときに使う。

## 検証前

- **一時Vaultに次のノートを置く。** 生成した原本とマニフェストは証跡へ残す
  - **机の今のノート:** 冒頭で「並べる相手」「並べる別の相手」へ wikilink する（関連に決定的に並ぶ）。2節以上。本文に「並べる相手」への wikilink も置く（本文のリンクから右で開く経路）
  - **並べる相手:** 40段落の長いノート。右で途中の位置を確かめられる長さ。**並べる別の相手:** 1節だけの短いノート
  - **大文字小文字だけ違う2ノート:** `refs/Case.md` と `refs/case.md`（それぞれ机の今のノートから wikilink）。プロバイダが大文字小文字を区別せず置けなければ、そのケースは**未実施**とする
  - **見つからなくなる相手:** 後で改名するためのノート（机の今のノートから wikilink）
- **開いた Fold（机・並べ読み・見開きのタブ）と、閉じた画面（スマホの形）の両方で行う**
- 時間は端末の時計で測る。30秒の境は ±3 秒の余裕を取り、境のすぐ内側と外側を分けて見る（25秒・35秒）
- 再会カードは Rediscover で同じノートを引き当てて出す（[reunion_card](reunion_card.md) と同じ出し方）。引き当てられなければ、そのケースは**未実施**とする
- 保存の確認には `_ReadingTraces/*.json` を pull して、訪問の `beside`（相対パスとタイトル）を見る。置く前に控える
- **端末AIは関係しない**（並べた相手の記録と再会の名前の行は AI を使わない）。本文の書き換え（蒸留の保存・太字の復元）が要るケースだけ、Nano が使えなければ未実施とする

## 射程外（自動テストが持つ順序）

正本 §10 が「実機で起こせない」と宣言した順序と、端末で作るのが現実的でない入力は、選抜の射程外とする（→ [README](README.md) 準備1）。

- 訪問の保存の途中で、並べた時間が30秒を越える順序（`ReadingTraceControllerTest`）
- 別端末で並べた訪問を、退避の読み戻しで合流する順序（`ReadingTraceMergeTest`）
- 相対パスが 1,024 バイトを超える・制御文字を含む相手、タイトルの 512/513 バイトの境（`BesideNotesTest`・`ReadingTraceControllerTest`）

## 後処理

- 共通手順の後処理に従う。一時Vaultと控えた JSON を消す。改名したノートと大文字小文字だけ違う2ノートも一緒に消す。
- `DESKMEM-17` の変異ビルドは、検証の後に戻したことを `git status` と組み立て直しで確かめる。
- **元Vaultへは戻さず、常設の検証用Vaultで終える。**

## 記録

- 通したケースIDと結果、`DESKMEM-02`・`DESKMEM-14` で pull した JSON の訪問の `beside`、`DESKMEM-17` の変異ごとの落ちたテスト名。
- オーナーの体感（`DESKMEM-01` の流れ、30秒が「並べて考えた」の線として妥当か）は合否と分けて残す。30秒は正本の仮の決定（判断4）の見直しの材料にする。
- 測っていないもの: 長く使ったときに名前の行がどれだけ役に立つか、相手の改名をどれだけ踏むか。
