# 返事保存のセッション分離を確認する

## 正本

正本: [reflect_reading_trace](../../dev/features/reflect_reading_trace.md)「返事の預け先」。

## 適用条件

準備・後処理は [共通手順](README.md)。既存の退避スキーマは変更されていないため、退避全ケースは対象にしない。

## 検証前

一時Vault A・BをSAFで許可する。本番ReadingTraceController・ReadingTraceStore・
SafReadingTraceDocumentGatewayを使い、遅延／保存失敗のみ一時DeviceProbeTestで注入する。
実プロバイダの自然な遅さと、注入した待ち時間を記録で区別する。

## ケース

| ID | 操作 | 期待 |
|---|---|---|
| `REPLYDEV-01` | ひとこと付き痕跡に返事を保存し、実SAFファイルを読み戻す | 改行を含む返事と元のひとことが一致する |
| `REPLYDEV-02` | Aの返事保存時の同期読込を保留し、保存Jobを取消して別セッションへ切り替え、読込を解放して新セッションを保存 | Aの返事が新セッションへ混ざらない。同一Vaultの別ノート／別Vaultの同名パスの両方で確認する |
| `REPLYDEV-03` | Aの返事書込を保留し、切替・取消後に保存失敗を返して、新セッションを実SAFへ保存 | 失敗側の預け直しでもAの返事が混ざらない。同一Vault／別Vaultを確認する |

## 後処理

最後に保存JSONを読み戻す。元ノートは書き換えない。常設検証用Vaultを選択してから一時物を削除する。

## 記録

ケースIDごとに入力・操作・期待・実測・判定を最新レビューへ残す。注入と実操作、未確認範囲を区別する。
