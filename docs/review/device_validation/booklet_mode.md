# 冊子モードの実機検証ケース

## 正本

- 冊子の判断・受け入れ条件: [booklet_mode](../../dev/features/booklet_mode.md)
- 全画面ルートとスクロールの前例: [note_fullscreen](../../dev/features/note_fullscreen.md)
- 共通の準備と後処理: [Codex実機検証手順](README.md)

## 適用条件

冊子ルート・扉（代表文）・束の寿命・「これを読む」の遷移・**紙面の形**を変えたときに使う。
**ナビゲーションのスタックを触ったときは必ず通す** — 冊子から戻れなくなる型は
`navigateToTab` を1回使うだけで再発する。

## 検証前

- 一時Vaultには**15本以上**のノートを置く（10枚の束と「もう10枚」を見るため）。
  **`BOOK-19` 用に3本だけのVaultも別に用意する**（`min(10, 利用可能数)` の側を見るため）。
- fixture を混ぜる。**4本のバッククォートで囲んだコードブロックを持つノート**（中の ``` 行を閉じと誤読しない）、
  **見出しとリンクだけのノート**（扉がタイトルになる）、
  **40字を超える1文で始まるノート**（省略記号が付く）、
  **frontmatter とコードフェンスで始まるノート**（どちらも扉にならない）。
- 冊子で読書痕跡が増えないことを見るので、**開始前に `_ReadingTraces` の件数を数えておく**。

## ケース

| ID | 入力・操作 | 期待 |
|---|---|---|
| `BOOK-01` | ノートタブの📖を押す | 冊子が開き、**下部ナビ（バー／レール）が出ない**。1枚目の扉が出る |
| `BOOK-02` | 左スワイプで数枚めくる | 次のページへ進む。扉は**待たずに**出る（AI生成の待ち時間が無い） |
| `BOOK-03` | 見出しとリンクだけのノートのページを見る | 扉が**ノートのタイトル**になっている。空のページにならない |
| `BOOK-04` | 40字を超える1文で始まるノートのページを見る | 40字で切られ、末尾が `…`。文字が途中で壊れない |
| `BOOK-05` | 3枚目まで進めて「これを読む」を押す | 通常のノート表示へ移り、**そこで初めて**要約・関連ノートが動き出す |
| `BOOK-06` | `BOOK-05` の直後にシステムバック | **同じ10枚の3枚目**へ戻る（束もページ位置も残っている） |
| `BOOK-07` | `BOOK-05` の後に別タブ（AI・さがす）を押し、ノートタブへ戻って📖を押す | **新しい10枚**が出る（前の束は畳まれている） |
| `BOOK-08` | 冊子を開いたまま端末を回転／Foldを開閉する | 冊子のままで、**ページ位置も保たれる** |
| `BOOK-09` | 末尾まで進める | 「ここまでの10枚でした。」と**もう10枚引く**が出る。自動で次が継ぎ足されない |
| `BOOK-10` | 「もう10枚引く」を押す | 新しい束の1枚目から始まる。**直前の束と同じノートが混じってよい** |
| `BOOK-11` | 冊子を数往復しためくった後、`_ReadingTraces` の件数を数える | **開始前から増えていない**。閲覧履歴にも冊子で眺めただけのノートが出ない |
| `BOOK-12` | 冊子を開いたまま、PC側で束に入っているノートを1つ削除し、そのページへ移動する | **そのページだけ**「このノートは開けませんでした。」。「これを読む」が押せない。他のページは読める |
| `BOOK-13` | 冊子を開いたまま Vault を切り替え、📖を押す | 新しいVaultのノートで束ができる。**旧Vaultのノートが混じらない** |
| `BOOK-14` | ノートが0本のVaultで📖を押す | 「引けるノートがありません。」。冊子から戻れる |
| `BOOK-19` | ノートが3本のVaultで📖を押し、末尾までめくる | 3枚で終わり、終端が**「ここまでの3枚でした。」**（10枚と出ない） |
| `BOOK-20` | 扉がまだ出ていない（spinner）ページで「これを読む」を押す | **押せない。**扉が出てから押せるようになる |
| `BOOK-21` | 本文を5秒だけ読んで📖を押し、冊子を20秒眺めてから別のノートへ渡る | 5秒のノートに**訪問が記録されない**（冊子の20秒が読書時間に入らない） |
| `BOOK-22` | 遅いプロバイダで「これを読む」を押し、本文が出る前にシステムバックで冊子へ戻る | 冊子の背後で**要約・関連ノート・履歴・痕跡が始まらない** |
| `BOOK-23` | 本文を5秒読んで冊子へ入り、冊子のままホームへ出て復帰し、20秒後に別ノートへ渡る | 5秒のノートに**訪問が記録されない**。背面復帰で冊子中の読書時間を再開しない |
| `BOOK-24` | 冊子から遅いノートで「これを読む」を押し、本文読込完了前にホームへ出る。背面で読込完了後20秒待って復帰し、別ノートへ移る | 読込対象のノートに**訪問が記録されない**。停止中に作られたSessionは復帰まで計測を始めない |
| `BOOK-26` | 冊子と通常のノート表示を**続けて開き、並べて思い出す** | **一目で別の面だと分かる。** 冊子は角が立った紙で、四辺の余白と紙の下の地が見えている。通常表示は丸いカードのまま |
| `BOOK-27` | 冊子の1枚目〜9枚目を見る | 紙の**右下に背後の縁が2枚**覗いている。縁が紙からはみ出して隣のページに重なっていない |
| `BOOK-28` | 末尾の「もう10枚引く」ページを見る | **背後の縁が無い**（束の10枚に含まれないページなので、まだ残っていると読めない） |
| `BOOK-29` | ダークモードで `BOOK-26`〜`BOOK-28` を通す | 縁が**紙より暗い側**に沈んで見える（ライトと同じ向き）。縁が紙より明るく浮いていない |
| `BOOK-30` | 幅の狭い端末／分割画面で冊子を開く | 扉の1行・ノート名・「これを読む」が**すべて紙の中に収まる**（余白を広げたぶんで押し出されていない） |
| `BOOK-15` | 冊子を開いたままアプリを終了し、タスクから復帰する | **ノートタブへ戻る**（空の冊子を見せない） |
| `BOOK-16` | TalkBack を有効にし、冊子を開く | ページ位置が「3/10ページ」と読み上げられ、**次のページへ／前のページへ**の操作でめくれる。読書ボタンは**「〈ノート名〉を読む」**と読み上げられる |
| `BOOK-17` | 初回セットアップ状態（Vault未選択）でノートタブを見る | ボタンが3つ並んでも**主（別のノートをひらく）と副（📖）が見分けられる**。📖は押せない |
| `BOOK-18` | `BookletScreenTest` を `am instrument` で実行する | 14件すべて成功。扉の描画と「これを読む」の配線が確認される |
| `BOOK-25` | `BookletNavigationTest` を `am instrument` で実行する | 2件すべて成功。**冊子→ノート→戻るでページ位置が残る**ことが NavHost 越しに確認される |

## 後処理

- 常設検証用Vaultへ切り替えてから、ケース別一時Vaultだけを削除する。元Vaultへは戻さない。
- `BOOK-05` で開いたノートには訪問が記録される。**一時Vault内なのでVaultごと削除すれば残らない。**

## 記録

ケースIDごとに入力・操作・期待・実測を対応させ、レビュー本文へ残す。
**扉が期待と違った回は、そのノートの冒頭数行をそのまま控える**
（→ [booklet_mode](../../dev/features/booklet_mode.md) §10 の受け入れ条件を見直す材料になる）。
**`BOOK-11` の痕跡件数は開始前と終了後の両方を数値で残す** — 「増えていない」は
記憶では確かめられない。
**`BOOK-26`〜`BOOK-30` は佇まいのケースなので、スクリーンショットを残す**（冊子・通常表示・
末尾ページの3枚、明暗それぞれ）。**形の判定はここにしか無い** — 形の役割が取り違えられていないことは
`BearingChannelTest` が固定するが、**それがどう見えるかは走査では分からない**
（→ [lessons](../../dev/lessons/L55.md) L55・[L53](../../dev/lessons/L53.md)）。
