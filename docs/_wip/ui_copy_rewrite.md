# UI の文言の書き換え案（オーナー確認用・使い捨て）

規則の正本は [ui_copy](../dev/system/ui_copy.md)。ここは今の文と案を並べただけで、書き換えが終わったら消す。
「規則」の数字は ui_copy §2 の番号。**太字の行は、設計書の仕様も一緒に直すもの。**

## 4. 蒸留

| 箇所 | 今 | 案 | 規則 |
|---|---|---|---|
| 面の説明 | AIが重要な箇所を選び、確認した箇所だけをノート内で太字にします。 | 要点を選んで、太字で残す | 2 |
| 範囲のシートの説明 | 端のつまみを引くと、好きな範囲にできます。太字にできるのは、この文の内側だけです。 | （文を消す。つまみの形で伝える） | 2 |
| **太字が多いとき** | ! 太字が目安の30%を超えます。多すぎると要点が目立ちにくくなりますが、このまま保存できます。 | 太字が多めです。このまま保存できます | 3・4 |
| **既にある太字だけで多いとき** | ! 既にある太字だけで目安の30%を超えています。足したい箇所は自分でチェックできます。 | 既にある太字だけで多めです。足したい箇所は自分でチェックできます（契約テストが「自分でチェックできる」の意味を見るので残した） | 3 |
| 確定の確認の注記 | 変更後の太字率は %.1f%% で、目安の30%%を超えます。 | 太字が多めになります | 3 |
| 確定の確認の警告（赤字1行） | 元の文字は削除しません。この操作の取り消し機能はありません。 | 1行目「文字は消えず、太字が加わります」／2行目（赤）「取り消せません」 | 6 |
| 復元の確認 | 現在のファイル内容は保存前の本文で置き換わります。必要なら先に別ファイルへ書き出してください。 | 今のファイルが、保存前の本文に置き換わります | 4 |
| 維持の確認 | 保存前の本文を保持している復旧情報を削除します。この操作後はアプリから復元できません。 | 1行目「保存前の本文を消します」／2行目（赤）「この後は復元できません」 | 3・6 |
| 範囲のシートの取り消し | キャンセル | やめる（何も書き換えない） | §3 |
| 大きすぎるノート | このノートは256KBを超えるため蒸留できません。 | 大きすぎるので蒸留できません | 3 |
| 文字を確かめられないノート | このノートはUTF-8として安全に確認できないため蒸留できません。 | 文字を確かめられないので蒸留できません | 3 |
| 長いノートの表示 | 大きすぎるため先頭1MBのみ表示しています。 | 大きすぎるので、初めの部分だけを出しています | 3 |
| 保存の途中の失敗 | 保存が中断されたか、ファイルが外部で変更されました。現在のファイルを維持するか、保存前へ復元してください。 | 保存が途中で止まったか、外で書き換えられました（下の2つのボタンで選ぶ） | 2・4 |
| 元のノートを開けない | 元のノートへアクセスできません。保存前の本文を別ファイルへ書き出してください。 | 元のノートを開けません。保存前の本文は書き出せます | 4 |
| 復旧の情報が壊れた | 復旧情報が破損しています。現在のファイルを確認してから復旧情報を破棄してください。 | 保存前の本文を読み取れません。今のファイルを確かめてから消せます | 3・4 |
| 外で書き換えられた | ノートが外部で変更されています。再解析してください。 | ノートが外で書き換えられました。選び直せます | 3・4 |

## 8. 端末 AI の失敗（AI-11）

失敗を種類で分けて、画面の文を1か所で決める。生の例外の文と `Unknown error` は画面に出さず Log へ。

| 種類 | 案 |
|---|---|
| 混み合って断られた | 端末のAIが混み合っています。少し待つと使えます |
| モデルを準備中・未取得 | 端末のAIを準備しています |
| ノートを読み込めない | ノートを読み込めませんでした |
| 生成に失敗した | うまく生成できませんでした |
| モデルの取得で通信する | モデルの取得で通信します（今の「通信量を確認してから開始してください」） |
| 使えない機能 | 〇〇をいま使えません。時間をおくと使えます |

## 変えないもの

- 4つのタブの見出し（Rediscover・Explore・Connect・Reflect）と関連の札 `linked`（ブランドの語、ui_copy §4）
- 痕跡の整理の確認の「削除／キャンセル」、蒸留の確定・復元・維持の確認の「キャンセル」（取り消せない操作の重い組）
- メモがいっぱいのとき「このノートのメモがいっぱいです。1件消すと置けます」（次の行動を言っている）
- 「読み取れない」と「見つからない」の区別、まだ書き戻していないこと、平文がクラウドへ渡ること（言い方だけを変える）
