# 実験の記録

**状態:** 置き場のみ。開発の仕組みを変えて試したときに、1つの実験につき1本を置く
**正本:** 仕組みそのものの正本は [../README.md](../README.md)。ここは試した結果の記録である

開発の仕組みには、スコアのような1つの物差しが無い。それでも、変えたことと結果を並べて残せば、
続けるか戻すかを記憶ではなく記録で決められる。

## 1本に書くこと

ファイル名は `YYYY-MM-DD-<内容>.md`。次の見出しで書く。

1. **変えたこと** — 何を、なぜ変えたか。仕組みの正本のどの節にあたるか
2. **比べ方** — 前と後をどう比べたか。比べていないなら、そう書く
3. **結果** — 1回ごとの結果。レビューの往復なら、回ごとの P1〜P3 の件数と、指摘が直ったか
4. **時間とトークン** — 1回ごとの秒数とトークン。どこで測ったか
5. **人の手が要った場面** — オーナーが判断した・中継した・止めた場面と、その理由
6. **分かったこと** — 次に変えるならどこか。続けるか戻すかの判断はオーナーが書く

書いた後は、事実の誤りの訂正のほかは書き換えない。
