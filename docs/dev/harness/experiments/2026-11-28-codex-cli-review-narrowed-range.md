## 分かったこと

- 追加の回で範囲と読む箇所を絞ると、1回のトークンはほぼ半分になった。前の回で読み終えた範囲を「対象外」と書いても、Codex は前回の指摘の判定と新しい指摘の両方を返した
- 堂々巡りの判定は指摘IDで数えるので、直すたびに外側の層で残りが見つかる形も止める。止めた後に続けるかは、判定の根拠（同じ所か、1つ外側か）を見て決めると速い
- 観点のファイルを scratchpad に置くと、セッションの再開で消える
- 続けるか戻すかはオーナーが決める
