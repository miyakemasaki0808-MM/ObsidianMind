# ADR-0005: 佇まいのチャネルは1つの意味だけに割り当てる

**状態:** Accepted
**決定日:** 2026-09-01
**詳細の正本:** [system/bearing_channels.md](../system/bearing_channels.md)

## 文脈

年代を紙の地色で伝える機能が入った後、佇まいで伝える案が4件並んだ — 分野を色帯で示す・
読書専用の書体を選ぶ・再会を演出で見せる・冊子と通常表示を見分けさせる。
**どれも「もう1本、色か形か動きを足す」形をしており、同じチャネルを取り合っていた。**
分野の色帯は最大の懸念に「地色と色符号が2本になる」を挙げ、再会の演出は
「どちらが主役か先に決める」と書いていた — **同じ問題を2件が別々に心配していた。**

## 決定

**チャネルと意味を1対1に固定する。** 色＝年代／形＝その面の役割（眺める・読む）／
位置と本数＝分類／書体と行間＝何も表さない／動き＝出来事の強度（2026-09-03に手触りの行を分けた）。

- **形を役割に割り当てた理由は「次の項目へ語彙を渡せるか」。** 3候補はどれも
  「その画面を区別できるか」だけなら成立したが、後続はトグルという**見た目を持つ操作子**を足す。
  字組みと動きはトグルに服を着せられない。
- **書体・行間は区別のチャネルから降ろす。** 読みやすさの設定としては残す。
  負わせると主役が2つになり、同じ問いに2つの答えが出る。

## 帰結

- **色を足す提案は、年代を降ろす提案と同義である。** そう書かずに出てきたら割り当てが崩れている
- **チャネルを足す提案は、表のどの行を空けるかとセットで出す**
- 区別は値ではなく**役割の違い**として持つ。同じ値を直書きすると、次に誰かが「揃えたほうが綺麗」と言った瞬間に戻る
