# ADR-0005: 佇まいのチャネルは1つの意味だけに割り当てる

**状態:** Accepted
**決定日:** 2026-09-01（2026-11-26 に書体・行間と、動きの3行目を改めた）
**詳細の正本:** [system/bearing_channels.md](../system/bearing_channels.md)

## 文脈

年代を紙の地色で伝える機能が入った後、佇まいで伝える案が4件並んだ — 分野を色帯で示す・
読書専用の書体を選ぶ・再会を演出で見せる・冊子と通常表示を見分けさせる。
**どれも「もう1本、色か形か動きを足す」形をしており、同じチャネルを取り合っていた。**
分野の色帯と再会の演出は、**同じ問題を別々に心配していた。**

## 決定

**チャネルと意味を1対1に固定する。** 色＝面ごと（読む面＝年代／冊子の面＝分野、2026-09-09）／
形＝面の役割／位置と本数＝分類／書体と行間＝ノートの型（読む面、2026-11-26）／
動き＝出来事の強度（2026-09-03に手触りを分割、2026-11-26に結晶の一覧の空気を足す）。

- **形を役割に割り当てた理由は「次の項目へ語彙を渡せるか」。** 3候補はどれも
  「その画面を区別できるか」だけなら成立したが、後続はトグルという**見た目を持つ操作子**を足す。
  字組みと動きはトグルに服を着せられない。
- **書体と行間には、分野ではなくノートの型を載せる。** 型は見出しの骨格とコードの枠で決まり、表示の前に分かる。
  分野は色が持ち、AIの判定は開いた後に届く。

## 帰結

- **色を足す提案は、その面の持ち主を降ろす提案と同義である。** そう書かずに出てきたら割り当てが崩れている
- **チャネルを足す提案は、表のどの行を空けるかとセットで出す。** 空けないなら、載る面を1つに限る（結晶の一覧の常時の動き）
- 区別は値ではなく**役割の違い**として持つ。同じ値を直書きすると、次に誰かが「揃えたほうが綺麗」と言った瞬間に戻る
