# ADR-0003: SAF参照を不透明化し `model` を依存グラフの葉に保つ

**状態:** Accepted
**決定日:** 2026-08
**詳細の正本:** [system/saf_boundary_gateway.md](../system/saf_boundary_gateway.md)

## 文脈

`model` の共有データ型が `android.net.Uri` を持っていた。プロジェクト内の依存は無く「葉」の条件を
満たしているように見えたが、**`Uri` は素のJVMではスタブが例外を投げる**ため、
**その型を組み立てられずテストが書けない**状態だった。

## 決定

**SAF参照を不透明な型の裏へ束ね、`model` から `android.*` を含むすべての外部依存を外す。**
「葉である」を依存の**向き**ではなく**素のJVMで扱えるか**で定義し直した。

- **引数として受け取って素通しする形は採らない** — 型として残る限りテストはその型を作らねばならず、
  作れなければその経路は検証できない。「依存を消した」ことにならない

## 帰結

- **`model` に `android.*` を import した時点で `PackageDependencyTest` がCIで落ちる**
- **Room の `@Entity` など、フレームワークのアノテーションも `model` へ置けない**
  （エンティティは `data` 内に定義し、`model` の型へマップする）
- `controller` が Android 非依存になったのはこの決定の副産物で、**JVMテストで並行処理を検証できる**のはそのため
