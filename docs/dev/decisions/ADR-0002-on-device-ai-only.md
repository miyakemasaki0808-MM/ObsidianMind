# ADR-0002: AIはオンデバイスのみ。ネットワーク権限を持たない

**状態:** Accepted
**決定日:** 2026-05（Gemini Nano 導入時）
**詳細の正本:** **本ADR**（この判断はこれまでどこにも記録されていなかった）

## 文脈

扱うのはユーザーのObsidian Vault、すなわち**個人の思考の全文**である。
クラウドAIを使えば品質は明らかに上がるが、その代償は「ノート本文を外部へ送る」ことになる。

## 決定

**AIはオンデバイスの Gemini Nano（ML Kit GenAI Prompt API）のみとし、`AndroidManifest.xml` にネットワーク権限を宣言しない。**

- **クラウドAIを採らない理由:** 本文送信が前提になる。「過去の自分の思考と再会する」場所として、
  送信の有無をユーザーが判断し続けねばならない設計は成立しない
- **ハイブリッド（任意でクラウド）を採らない理由:** 権限を1つ持った時点で「送っていない」を構造で保証できなくなる。
  **保証を設定画面の状態に委ねると、それは保証ではない**

## 帰結

- **品質の上限をNanoが決める。** 出力は256トークン上限・Mutex直列で1回数十秒。
  「速い要約」「大量生成」を前提にした機能は原理的に作れない（→ [system/background_ai_ux.md](../system/background_ai_ux.md)）
- **AI関連のコスト・トークン消費という概念が存在しない。** 課金計測の機能は動機ごと成立しない
- **Nano非対応端末では機能が丸ごと使えない。** 各機能は「AI非対応時の挙動」を必ず持つ必要がある
- **この決定を覆すには権限の追加が要り、それは上記の保証を失う**。機能の魅力だけでは覆らない
