# ADR-0006: 今のノートは主の面の1つだけ。複数インスタンスを採らない

**状態:** Accepted
**決定日:** 2026-10-04
**詳細の正本:** [system/fold_experience.md](../system/fold_experience.md)

## 文脈

開いた Fold を「思考を並べて考える机」として扱うと決めた。補助の面で別のノートを辿り、開閉をまたいで戻すようになると、
補助の面のノートも「今のノート」として扱いたくなる。Google の大画面の品質指針も、最上位の段で複数インスタンスの起動を挙げている。

## 決定

**今のノートはアプリ全体で1つで、主の面に置く。補助の面のノートは、眺めて探索する相手に留める。複数インスタンスは採らない。**

- **2つ目の今のノートを採らない理由:** ノート単位の契約（`cancelNoteScopedJobs()`・`withNoteScopedReset()`）と
  各 Controller の要求番号は、今のノートが1つであることを前提にしている。面ごとに持たせると世代の三層目が要り、
  旧ノートの状態残留が最も出やすい場所を作り直すことになる
- **複数インスタンスを採らない理由:** 痕跡の錠は調停側が1つ作って配っている。インスタンスごとに調停側ができると錠が分かれ、
  同じサイドカーを2つの錠で書く「錠はあるのに守られない」形になる

## 帰結

- 補助の面の Controller に、今のノートの切替・訪問の記録・余白メモを書く口を渡さない
- 補助の面に寿命を持たせるときも、世代の層を足さず [architecture](../system/architecture.md) 判断4 の既存の行に収める
- **覆すには、痕跡の錠を共有物から外す設計と、ノート単位の契約の作り直しが先に要る。** 機能の魅力だけでは覆らない
