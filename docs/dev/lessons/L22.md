# L22. 文字数の比率とトークンの比率は別物。最適化する前に測る

**教訓:** **予算・コスト・比率を語るときは、分母と単位を明示する。**
文字数で切った予算の話を、トークンの制約の話と地続きに扱わない。
同じ文字数でも言語と内容でトークン密度は大きく変わる。

**いつ当てるか:** 「〇〇が予算の N% を占めている」と書きたくなったとき。
測る手段が無いなら**「測ってから決める」と書いて止める**のが正しい。

**再発の証拠:**
- **2026-08-01** — AI入力の注意書きが「関連ノートの予算600に対して226文字＝**38%**」として
  長く最優先の改善候補に積まれていた。実測すると **44トークン＝完成プロンプトの1.7%**。
  **桁が違った。** 注意書きが英語で本文と候補が日本語だったため。
  さらに「38%」は完成プロンプトではなく**抜粋予算だけを分母**にした比率で、
  2つの誤差が同じ向きに効いて問題を実際より大きく見せていた。
  **止めていなければ、効かない最適化を実装していた。**
