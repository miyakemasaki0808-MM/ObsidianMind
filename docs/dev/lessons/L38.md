# L38: 検証の証跡を、検証せずに書いてしまう

**当てるとき:** 文書へ「いつ・どのコミットで確かめたか」を書こうとしている。

## 何が起きたか

`features/` 12本の `**最終検証:**` に、**Gitに存在しない7桁の英数字**が書かれていた。
それらしい形をしているので、指摘されるまで誰も気づかなかった。

**存在しないコミットを指す検証日は、検証していないことより悪い。**
読む側は「その時点では実装と一致していた」と信じてしまい、**疑う機会を失う**。

## なぜ起きたか

`最終検証` は「実装を当て直した証跡」なのに、**書く側が値を自由に作れた。**
本文の記述はコードを読んで書いたが、**ハッシュだけは確認せずに埋めた** —
形式を満たすことが目的化し、その欄が何を保証するためにあるかが抜けた。

**証跡の欄は、それ自体が検証されない限り、装飾にしかならない。**

## どうするか

- **`最終検証` には、実際に読んだコード状態のコミットを書く**（`git log --oneline -- app/src` で引く）
- **実在を検査へ載せる。** `AdrShapeTest` が `git cat-file -e` で全件を確かめる
- **`未確認` を恐れない。** 確かめていないなら日付を進めず、
  `> **未確認:**` で何が未突合かを書くほうが、偽の証跡より価値がある

> **一般化: 「確かめた」と書く欄を作ったら、その欄自体を確かめる仕組みを同時に作る。**
> 作れないなら、その欄は置かないほうがよい。
