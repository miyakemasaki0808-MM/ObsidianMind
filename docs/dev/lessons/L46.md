# L46. リフレクションで全欄を見る検査でも、**入力を手で書いていれば新しい欄は素通りする**

**いつ当てるか:** 状態型へ欄を足したとき／「全フィールドを見る」形の検査を書くとき
**検査:** `NoteSessionCoordinatorTest`「リセット検査の入力は全フィールドが初期値と異なる」。
リセット検査が新しい欄を素通りした仕組みと、入力を検査する理由は、このテストの KDoc が持つ

---

**「全部を見る」検査を書いたら、その「全部」がどこから来るかを1度たどる。**
判定がリフレクションでも、入力が手書きなら、守られる範囲は手書きの側で決まる。
入力が全欄を埋めているかは機械で確かめられるので、入力そのものにも検査を1本置く。

[L29](L29.md) と同じく、検査が守りたい対象より狭い範囲を数えていた形である。
狭さの出どころが、L29 は判定条件、こちらは**入力**にあった。
