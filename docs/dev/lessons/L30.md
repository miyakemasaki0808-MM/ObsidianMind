# L30. 失敗が「赤」ではなく「件数の減少」として出ると、誰も気づけない

**教訓:** **期待していた件数が出ていないことは、期待値を持っていない限り分からない。**
検査が走って赤も出ているのに、起動しなかったテストはどこにも数えられない。
「落ちるテストが無い」（[L11](../lessons.md#l11-テストが効いているかは変異させて確かめる)）とも
「検査が一度も走らない」（[L29](L29.md)）とも別の形である。

**いつ当てるか:** テストを足したとき。緑/赤ではなく、**足した数だけ実行件数が増えたか**を見る。
合わなければ、走らなかったものがある。

**検査:** `InstrumentationTestShapeTest`（式本体の `runBlocking` に `Unit` を明示させる）。
クラス全件が起動しなかった原因、書き方のほうを縛る理由、検査の対象外は、この検査の KDoc が持つ。
