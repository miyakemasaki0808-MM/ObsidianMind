# L50. **外から見える契約は、外から見える形で検査する。** decode した意味は形の欠落を通す

**いつ当てるか:** アプリの管理外へ出すファイル形式・利用者へ見せる文言を決めたとき
**検査:** `ReadingTraceBackupJsonTest`（生のJSONに `documentId` のキーが1つも無い／
非退避ファイルは入力形式によらず同じ文言）。内部表現で書いた検査が2件を実機検証まで残した経緯は、この2つのテストの KDoc が持つ

---

**「テストがある」ことは、契約が検査されている証拠ではない。** 退避ファイルの契約は2つとも外から見た形で書かれていたのに、
JVMテストは decode した値と型で書かれており、1,110件が緑のまま実機検証まで残った。

**当て方:** 受入条件が「外から見て何が見えるか」で書かれているなら、検査もその粒度で書く —
**生の文字列を検査し、文言は等値で比べる**。型や復元後の値は、その手前の性質でしかない（→ [L25](L25.md)）。
