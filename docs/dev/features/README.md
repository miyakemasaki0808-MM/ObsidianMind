# 機能仕様（features/）

**答える問い: この機能で何ができて、どう実現しているか。**
**書かないこと: 横断的な基盤の話**（→ [../system/](../system/)）。

- **様式は [`_template.md`](_template.md)。** 新しい機能文書はこれを写して始める
- **ヘッダ5行を必ず埋める。** 特に `最終検証` — **これが無いと文書が実装から離れたことを誰も検知できない**
- **履歴を書かない。** 「1巡目で〜だったが2巡目で〜」は [owner/journal/](../../owner/journal/) が持つ
- **覆りにくい重大判断は [../decisions/](../decisions/) にADRを立て、ここからリンクする**

一覧は [document_map.md](../document_map.md) §2 が持つ（**二重管理にしないため、ここには並べない**）。

> **[quiz.md](quiz.md) は 2026-08-11 の分割で「専用文書が無い」ことが判明した唯一の機能だった。**
> 空の器として置いて穴を可視化し、同日に実装から起こして埋めた。
> **分割の副産物として穴が見えた**のが要点で、器を揃えると欠けが露出する。
