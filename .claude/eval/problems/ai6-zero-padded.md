# 0で埋めた番号の箇条の中で、引用した問いを書き手の問いとして拾う

再会カードは、ノートの中の問い（「〜のか。」のような文）を候補に拾う。
引用した他人の問いは書き手の問いではないので、引用（素の `>` と `[!quote]`・`[!cite]` のコールアウト）の中の文は候補から外している。
ほかのコールアウト（`[!note]` など）の中の文は書き手のものとして拾う。

ところが、次のノートでは引用の中の問い「引用の問いなのか。」が候補に残る。

```
> [!note] メモ
> 01. > 引用の問いなのか。
```

`01.` の代わりに `0001)` と書いたときも、ふつうの段落の次の行に `01. > 引用の問いなのか。` と書いたときも同じである。

## 求めること

- 上の3つのノートでは、問いの候補を空にする
- `> [!note] メモ` の次の行の `> 01. > [!note] 自分の問いなのか。` からは、今までどおり「自分の問いなのか。」を拾う
- 引用と箇条の見分けについて、今のテストが確かめている振る舞いは変えない
