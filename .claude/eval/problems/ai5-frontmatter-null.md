# frontmatter の引用符なしの null を、タグや別名として読む

関連ノートは、frontmatter の `tags` と `aliases` を読んで根拠（共通のタグ）と AI へ渡す候補の文脈（別名）に使う。
frontmatter は確実に読める書き方だけを読み、読めない形が混ざったキーは推測せずにまるごと使わない方針である。

ところが引用符で囲まない `null`・`Null`・`NULL`・`~` を文字列として読むので、
`tags: [null]` から「タグ #null が共通」という根拠を出し、`aliases: [null]` では候補の文脈に `aka null` を渡す。
YAML（1.2 の Core Schema）ではこれらは値が無いことを表し、文字列ではない。

## 求めること

- 引用符で囲まない `null`・`Null`・`NULL`・`~` は読めない値として扱い、それが混ざった `tags`・`aliases` はまるごと使わない（フロー形式 `[...]` でも、`- ` で並べる形式でも）
- 引用符で囲んだ `"null"` や `'~'` は文字列として今までどおり読む
- `nullable` や `~x` のように語の一部であれば今までどおり読む
- 関連ノートの根拠と候補の文脈にも、値の無いタグや別名を出さない
