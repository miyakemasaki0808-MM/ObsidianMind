# 引用の前後を控える整え方に、制御文字が残る

余白メモで引用した箇所は、照らし直しのために前後の文字と位置の手掛かりを痕跡へ控える。
控える文字は照らし直しの整え方（`normalizeForMatch`）を通り、制御文字を含まない前提で痕跡の容量を見積もっている
（JSON では制御文字が1文字6バイトに膨らむ）。

ところが U+001C〜U+001F の4つの制御文字は、整えた後の文字に残る。

## 求めること

- 整えた文字には、どの制御文字（U+0000〜U+001F、U+007F〜U+009F）も残らない
- U+001C〜U+001F は区切りとして扱わずに落とす（`a<U+001C>b` は `ab`、`a <U+001F> b` は `a b`）
- この4つを含まない文字は、今と1文字も変わらずに整える。既存の控えと照合するので、全角空白やノーブレークスペースなどの扱いを変えてはいけない
